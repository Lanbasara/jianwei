# ADR 0001：独立的投资分析讲解能力

- 日期：2026-11-12
- 状态：接受

## 背景

AI 完成研究、投资建议或复盘，并不意味着最终的分析结果容易理解。用户需要看清判断依据、推断关系、条件分支或取舍，而不是追加研究或获得一份正式 HTML。现有 report 已承担专业编辑与 HTML 成稿责任，不应仅因输出格式不同而复制一个成稿器。

## 决定

依照[开发哲学](../../jianwei/PHILOSOPHY.md)，增加可以独立委托与组合的 explain，向用户讲清 AI 已形成的分析结果。它可以在同一任务中承接分析后的最终讲解，也可回应对已有分析的追问，不要求用户先表示看不懂或另交成稿。它不承担新的投资判断，也不是研究、建议或 report 的必经步骤；原能力仍对自身成果的基本可读性负责。report 及已有组合保持不变。

默认在对话中使用普通 Markdown，图形是按需选择的解释手段，纯文本图提供可移植的基础表达。不定义增强 Markdown 方言、统一图形模板或必须生成文件的流程；增强呈现须服从宿主能力与理解价值。具体职责、方法和完成标准由 [explain](../../jianwei/skills/explain/SKILL.md) 维护，不在本记录重复。

## 取舍与边界

相较于扩大 report，独立讲解能承接本次分析的最终解释，也能直接回应局部疑问，不要求正式成稿。相较于默认追加一轮润色或专门的画图能力，它以理解分析结果为目标，避免固定流程和形式反过来主导内容。

这种划分增加一项可选能力，但不保证原分析正确，也不证明实际讲解已经更易懂。离线检查覆盖装配与注册；忠实性和可读性由具体使用中的阅读判断，不能用图形数量或格式合规替代。
