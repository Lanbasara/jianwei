# ADR 0003：证据阅读视图与开放式研究

- 日期：2026-11-13
- 状态：接受

## 背景

开放式投资研究需要从多类信息中形成候选，再根据证据深入。专用数据和订阅源的成功响应可能仍不满足所需期间或覆盖；agent 自写的摘要也可能丢失原本已经返回的日期、警告与后续入口。重复追加研究规则不能修复这些不同层次的问题。

## 决定与责任

探源 CLI 提供显式的精简阅读视图，首批用于订阅新闻、快讯和网页搜索。它对已完成响应做确定性展示裁剪，保留来源、时间、覆盖和续查信息，声明展示省略。默认完整响应保持兼容；精简视图不改变查询、缓存或错误语义，也不生成投资判断。视图的字段与限制统一由 CLI 帮助维护。

探源 skill 负责引导 agent 比较实际材料与当前问题。专用来源不足时，可使用已配置且可用的 DeepSeek / Tavily 搜索补查公开证据；开放式发现也可以从搜索开始。提供方由 agent 根据缺口选择，不在 CLI 内隐式串联收费请求。合理补查仍不足时，允许作出有范围的无法获取判断并交付已能成立的部分。搜索未命中与搜索未能执行保留不同含义。

研究职责仍由见微 research 承担。对象可以由调查逐步发现；选择候选与继续调查的依据是它们对当前问题的解释价值和可检验性。方法允许不同入口、合理收束与初步候选交付，不要求穷尽来源、固定研究数量或新建发现 skill。历史档案与建议的权威边界沿用 WORKSPACE 和 advise。

## 取舍与边界

精简视图沿用工具字段而不猜测统一时间语义；完整读取与原文获取按 CLI 帮助进行。重新调用可能取得新响应，因此视图不承诺可恢复同一历史快照，也不增加持续采集或永久存储。

展示发生在既有工具返回之后，只处理明确支持的集合和文本字段；外部内容通过现有 JSON 编码输出，不被解释或执行。新增视图参数在取数前校验，不引入依赖、凭据访问、文件写入或额外网络调用。

可选工具组合只保留选材理由；参数、返回与错误定义归 CLI，补查方法在现有参考文档中按责任合并。后台任务等待、运行环境初始化和最终交付属于相应执行链路，不能通过本次展示或研究引导修改宣称已解决。

本次按用户要求不运行测试或行为验证，实际使用效果由用户验收；生成交付目录不构成研究质量的证明。
