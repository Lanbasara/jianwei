# 机会发现

承担发现与筛选候选方向的责任，帮助用户决定哪些变化或潜在机会值得进一步研究。交付可以止于有依据的候选及研究问题。

## 确定本次范围

根据用户意图确定相关市场、资产范围与时间尺度，沿用能够合理确定的背景；只有歧义会实质改变发现方向时才追问。尚无具体标的是这项能力的正常起点。

读取并遵循[工作区约定](../../WORKSPACE.md)，按本次问题查阅相关背景与已有成果，确定成果位置。历史关注方向可以提供线索，也应给当前信息中出现的新方向留下空间。

## 发现与筛选

从相互补充的信息入口形成候选，随着发现调整搜索的广度与重点。关注经营、供需、政策、价格或预期中有经济意义的变化与差异；热度和涨跌可以提供线索，入选理由需要说明它们可能怎样影响经济结果、现有价格或预期可能反映了多少。

使用 tanyuan 的取数、搜索与正文能力时，遵循其当前说明；也可使用 Web、用户材料和已有研究。补查与搜索兜底沿用探源的指引。对影响候选入选的关键事实做初步核验，区分新事实与旧材料再传播、独立依据与重复转引，并寻找足以推翻初步解释的证据。根据核验结果保留、调整或放弃候选。

比较候选为什么值得现在关注、相较其他方向有何优先理由，以及哪项未知最可能改变这个判断。调查深度以足以支持筛选为准；继续取数若能明显改变候选优先次序或入选理由，就针对该缺口展开。材料只能支持初步线索时，保留其判断强度，不因需要交付而补造机会。

## 按需协作

需要深入论证某项事实、机制或证券价值时，用 [research](../research/SKILL.md) 解决具体问题，提供材料与待检验的解释，接受其支持、修正或否定，再更新候选判断。也可按需使用宿主原生协作调查相对独立的方向，由负责发现的 agent 综合比较并交付。已有明确研究问题可直接进入 research，无需先完成发现。

## 交付

用自然语言说明值得关注的候选、当前关注理由、优先次序与关键待研究问题，引用足以支持筛选的来源，保留时点、实际覆盖范围及重要缺口。组织与候选数量随任务决定；没有足够依据选出候选时，说明发现范围和局限。成果按工作区约定保存，后续深入研究可从这些材料和问题开始。

当进一步调查预计不再明显改善本次筛选时，可以完成交付。买卖或配置选择由 [advise](../advise/SKILL.md) 在用户需要时结合当前条件处理；候选入选本身不构成行动建议。
