# 投资复盘

帮助用户深入理解已经发生的市场与投资经历，发现认识和决策过程中值得保留、修正或继续研究的地方。承担经过重建、原因辨析与综合评价的责任，说明本次发现对后续思考的具体意义。

## 理解本次问题

从用户当前想理解的问题确定对象、范围与深度。市场或行业演变、一次投资、某项研判或建议、一段时期的选择都可以独立复盘，无需先有持仓、交易、旧预测或 Jianwei 研究。沿用能够确定的背景，只有歧义会实质改变分析方向时才与用户对齐。

读取并遵循[工作区约定](../../WORKSPACE.md)。从相关对象、日期或 case 入口逐步查阅材料，随着发现深入原始依据；本次问题决定历史的使用范围，无需从上次复盘继续，也无需先读完全部历史。旧复盘可以帮助定位问题和复用工作，其结论仍须结合当前问题与条件审视。

回顾一段时期或多个案例时，说明实际覆盖范围与选择依据。关注与问题相关的成功、失败、未参与和仍未揭晓的情况，避免仅凭最醒目的案例评价整段历史。缺少记录时交付仍有依据的局部分析，说明缺口限制了什么。

## 理解经过、解释结果

围绕影响问题的重要变化重建经过，区分事件发生、信息公开和作出判断的时点。解释需求、供给、经营、定价、资金或预期等相关因素怎样传导，辨别事实变化与市场价格对预期变化的反应。时间上的先后和走势相似只是线索；比较有意义的竞争解释，寻找能够区分它们的证据，不以完整流畅的故事代替论证。

涉及旧判断时，恢复当时的主张、理由、对象、期限、条件和表达的把握程度；涉及选择时，结合当时相关目标、约束与可行方案。区分当时实际采用的信息、合理能够取得的信息和后来才出现的信息。后来的回忆注明来源，记录不足的部分保留未知，不替过去补写概率、理由或行为。

分别检验当时的论证是否有合理依据，以及后来的发展究竟支持、削弱或尚未检验哪一部分。比较对象、口径、期限与条件应当对应；结果兑现不自动证明原解释，结果不利也不直接证明选择错误。不确定性不能使原判断免于检验，单次结果也不足以评价概率校准或长期能力；多份材料重复同一观点不增加独立证据。

涉及投资表现时，按相关目标与适当的比较基准理解收益、损失和风险的来源，辨别市场变化、投资选择、配置和实施等因素的作用。贡献分解与经济解释分别论证，关键计算保留输入、口径、公式与假设。数据只能支持局部分析时限定结论，不以补齐完整账户核算为前提。

解释预期与现实的差异时，检查信息、推理、原有条件和后续选择中哪些环节实质影响了结果。对发现的遗漏或改进建议，说明依据，并检验当时修正它会改变方向、幅度、时机、确定程度还是不改变选择。反事实比较使用当时有意义的可行方案，保留假设；避免事后挑选最优结果，也不要把尚不能排除的解释定为原因。

评价行动、持有、等待或不参与时，同样审视其理由、机会与代价。有后续材料时，检查重要信息变化后是否合理调整认识与选择；区分原判断存在问题、原条件后来改变和原本接受的风险发生。分别评价建议和用户实际选择，也审视 Jianwei 自身的分析与表达。目标是改善理解与选择，不预设应更保守、更频繁交易或始终坚持原计划。

## 证据与协作

按需使用用户材料、已有成果、[tanyuan](../tanyuan/SKILL.md)、Web 与计算工具。核对关键来源及其资料时点，区分事实、估计、假设和推断；把后续解释与当时原始材料分开，使主要结论可追查。补充调查应能改善当前解释或评价；不能解决的缺口明确其影响，不把未知包装成确定结论。

需要深入调查某个事实、机制或证券价值时，可用 [research](../research/SKILL.md) 解决具体问题；需要展开组合关系或变化影响时，可用 [portfolio](../portfolio/SKILL.md)。也可按需使用宿主原生协作能力调查相对独立的问题或检验关键解释。委派明确子问题、必要材料与产物位置，负责复盘的 agent 综合证据、回应重要异议并完成原问题；新增协作应带来相称的分析价值。

本次复盘可以独立结束。用户还需要判断当前行动时，由 [advise](../advise/SKILL.md) 使用相关成果并结合当前条件比较选择；对过去的评价本身不足以直接推出当前买卖方案。

## 交付

用自然语言 Markdown 回答本次问题，先说明最重要的发现，再展开经过、证据、解释与限制。说明哪些认识得到支持、需要修正或仍无法判断，以及这对后续研究或选择意味着什么。改进建议具体到相关问题及其依据；篇幅和组织随任务决定，无需固定栏目、评分表或每次提炼一条通用教训。

正式复盘成果按工作区约定保存在 case，由 `case.md` 链接主要分析和必要底稿；引用本次实际使用的历史记录与来源，保留读懂结论所需的摘要。复盘发现与改进建议作为本次有条件的分析成果保存，历史复用与后续更新遵循共享约定。

交付前检查：是否解释了本次最值得理解的问题，主要因果解释与评价是否有证据支持，重要竞争解释是否处理或保留，实际覆盖范围和未知是否清楚，以及发现的意义是否具体。进一步工作不再带来相称改善时，交付已经成立的判断和未解决部分；完成不以发现错误、形成交易建议或总结长期原则为条件。
