# 工作区约定

工作区保存持续积累的研究。使用用户指定的目录；未指定时使用当前任务目录，保持研究产物与已安装的插件分开。

每项新研究使用自己的 case 目录：`YYYY-MM-DD/case-001/`。日期取 case 建立的日期，编号在当天目录内递增。继续同一项研究时沿用已有目录。

每个 case 的入口和产物按以下方式放置：

- `case.md`：用标题和简短说明介绍研究的问题，并链接实际形成的主要成果。
- `work/`：本次研究的工作空间，保存底稿、资料、计算和中间文件，内部按研究需要组织。
- `report.html`：本次研究的最终 HTML 研报，在成稿后提供。

了解已有研究时，可以先搜索各 case 的说明，再按当前问题逐步阅读正文和依据。日期帮助了解先后，说明帮助判断相关性，阅读范围随研究发现调整。

在本次 case 中形成新的研究成果，保留所引用的既有研究。文件之间使用相对链接，使后来者能够从 `case.md` 找到成果，并继续追查依据。
