# 组合分析

解释这些投资放在一起意味着什么：收益依赖什么条件，哪些部分互补或重复，重要风险如何共同发生，以及某项变化会怎样影响整体。承担组合层面的推理、计算与综合判断，交付能够支持理解和选择的分析。

## 明确分析对象

从当前问题确定分析范围与深度。实际持仓、局部账户、假设配置和调整方案都可以独立分析；既可以评价现有结构，也可以只回答某项关系或变化的影响。读取并遵循[工作区约定](../../WORKSPACE.md)，渐进查阅相关背景与已有成果，无需先有 `portfolio.md` 或完成一次 research。

建立可比较的组合视图：分清实际与假设、覆盖范围、资料时点，以及涉及的金额、数量、权重基数、币种和单位。说明未覆盖部分对结论的影响。零散或不同时点的数据可以支持局部判断；需要汇总、换算或比较时，先处理口径差异，保留估计依据和限制。

用户的目标、约束与预期资产角色仅在影响当前分析时澄清，已有明确表达可以复用。缺少权重仍可讨论关系，缺少个人目标仍可分析结构；只有会实质改变当前判断的信息才值得进一步提问或调查。分别交付已经成立的结论与仍依赖未知条件的部分。

## 分析组合如何运作

穿透影响判断的投资工具，区分直接持有、间接持有和共同经济依赖。汇总同一底层暴露时按组合权重逐层计算，避免将基金及其底层持仓重复相加；披露不全的部分保留未知。持仓名称不同也可能依赖同一需求、价格、融资条件或其他因素。资本占比与风险贡献分别解释，不能用前者直接替代后者。

把收益来源与风险放在同一逻辑中理解：哪些条件推动组合表现，这些条件为什么可能成立，失效时哪些部分会一起承压，哪些部分提供不同的收益来源或缓冲。以机制和证据检验资产角色；用户的原定用途与分析判断分别呈现。集中、重复或持有现金是否值得关注，取决于其影响及已知目标，不预设分散程度越高越好。

围绕主导结论的因素检验组合韧性。按问题选用敏感性分析、相互一致的情景或从难以承受的结果反推条件，解释变化怎样传导至组合；兼顾有意义的有利与不利情况。相关性与历史表现应注明样本和适用条件，不能单独证明经济关系或未来保护作用。情景后果与发生概率分开，证据不足时用方向、范围或条件表达。

分析调整的边际影响时，用一致口径比较调整前后，明确资金来自新增投入、现有现金还是替换其他投资，说明哪些暴露、收益来源和代价发生变化，哪些仍然存在。依据给定目标可以判断方案的适配程度；尚未确定的重要取舍留给用户或后续建议，不把某种配置当作普遍最优。

计算和模型服务于上述判断。方法、数据与精度应匹配当前问题；保留重要公式、输入、时点和假设，让关键结果可以复算。使用风险指标或优化结果时说明它们捕捉了什么、遗漏了什么，检验影响结论的参数变化。分析的价值在于解释重要关系及其后果，不以指标数量或数值精细度衡量质量。

## 证据与协作

按需使用用户材料、已有研究、[tanyuan](../tanyuan/SKILL.md)、Web 与计算工具。区分事实、估计、假设和推断，引用支持结论的具体来源及资料时点；转述和复用时保留这些区别。同一来源的重复引用不会增加独立证据。

需要进一步调查某个标的、机制或证券价值时，用 [research](../research/SKILL.md) 解决明确的问题，再综合其对组合的意义。可以使用宿主原生协作能力并行调查相对独立的问题，或独立检验关键推断与计算。委派时给出问题、必要输入与产物位置；承担组合分析的 agent 负责处理口径差异、证据冲突和跨标的关系，不能以单项结论的拼接代替整体判断。

每次追加协作应能补充影响结论的证据、检验推断或澄清冲突。保留当前任务的完成责任，将超出委托范围的目标与取舍交回负责该问题的人或 agent。进一步工作不再带来相称改善时，交付有依据的判断和剩余缺口。用户还需要决定采取什么行动时，可由 [advise](../advise/SKILL.md) 使用本次成果比较选择；组合分析本身可以独立结束。

## 交付与沉淀

用自然语言 Markdown 回答当前问题，优先解释主导结论的组合关系及实际意义，再展开证据、计算、条件与重要未知。涉及已有目标时说明适配与冲突；涉及方案时说明相对变化及代价。篇幅和组织随问题决定，避免逐个介绍资产却没有组合判断。

按工作区约定把分析与底稿保存在 case 中，由 `case.md` 链接主要成果。引用本次实际使用的持仓记录和研究，保留读懂结论所需的摘要；新证据或条件带来的重要判断变化留下可追溯说明。`portfolio.md` 的写法遵循共享约定，组合推断与假设配置留在分析成果中。

交付前检验：结论是否回答了当前问题，重要暴露是否遗漏或重复计算，主要推断是否经得起相关反例与假设变化，数字是否可复算，未知是否改变了结论的适用范围。明确已经完成的判断及尚不能判断的部分，无需以一次买卖建议或完整的财务盘点作为完成条件。
