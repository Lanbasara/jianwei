# 形成建议并讲清取舍

先读取并遵循 [advise](../advise/SKILL.md)，让它独立完成当前选择的分析、方案比较与建议判断。

达到 advise 的完成条件后，读取并遵循 [explain](../explain/SKILL.md)，默认在当前上下文中完成讲解。需要独立阅读视角或较大表达工作量时，可以委派子智能体读取并遵循 explain，其能力与工具按本次讲解需要选择。委派时交代用户原问题与表达要求、本次任务背景，以及完整的建议、支撑分析与必要依据；结果保存在底稿时，给出具体位置。

主智能体负责最终交付；如有委派，先核对讲解未改变原分析的判断、依据与条件。用户无需在建议形成与讲解之间再次发起请求。
