# 形成建议并讲清取舍

先读取并遵循 [advise](../advise/SKILL.md)，让它独立完成当前选择的分析、方案比较与建议判断。

达到 advise 的完成条件后，将结果讲解工作委派给具备完整工作能力的通用子智能体，由它读取并遵循 [explain](../explain/SKILL.md)。向它交代用户原问题与表达要求、本次任务背景，以及完整的建议、支撑分析与必要依据；结果保存在底稿时，给出具体位置。让它自主使用宿主提供的工具完成讲解，不将其限定为只读或探索型智能体。

主智能体接收讲解并向用户交付，用户无需在建议形成与讲解之间再次发起请求。
