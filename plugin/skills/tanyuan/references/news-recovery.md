# 寻找历史新闻材料

RSS 和快讯未提供目标材料时，可以改查发布者归档、公告或定向搜索。请求失败与其他取数缺口统一按 [补查路径](error-playbook.md) 处理。

| 情况 | 下一步 | 限制 |
|---|---|---|
| 响应缓存丢失 | 重新调用工具 | 上游当前内容可能已经变化 |
| 本地正文丢失 | `fetch.url` 使用 `refresh=true` | 只能取得网站当前可访问版本 |
| RSS/快讯窗口没有目标 | 查官方归档、公告、定向搜索 | 不能通过重复查询保证恢复旧条目 |

## 可尝试的入口

1. 公告与官方数据:`filing.announcements`、`filing.sec`、对应宏观工具。
2. 发布者提供的归档页面或可访问的原始文件。
3. 定向搜索：按 [搜索指南](search-guide.md) 组合机构、实体、事件和期间，找到候选后读取原文。
4. 官方或聚合订阅源可提供仍保留的线索；时间范围只是过滤条件，不能据此承诺历史覆盖。

返回条目的最早日期不等于来源的保留期限；只有来源说明或其他证据足够时，才判断窗口确实已过。补查后如何结束取数，沿用主 skill 的完成判断。

本工具不提供新闻历史归档服务。缓存和正文 blob 有容量限制,不能当作永久档案;
需要长期留存时由上层工作区或数据管道单独保存。
