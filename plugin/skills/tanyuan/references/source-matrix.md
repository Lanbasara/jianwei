# 来源与能力限制

来源优先级用于路由,不保证可用性或语义正确。以本次响应的来源、单位、时间和告警为准;
可用 `ty doctor` 检查当前连接状态。

| 能力 | 来源 | 使用限制与核验路径 |
|---|---|---|
| A 股及港美股行情/K 线 | 腾讯 | 留意市场、交易时间、复权和成交量单位;实时行情不等于历史收盘 |
| A 股日线、估值、资金流 | Tushare | 各接口的单位不同;请求字段、来源日期和权限分别核对 |
| A 股公告 | 巨潮 | 以公告原文核验,区分公告日与报告期 |
| 美股披露 | SEC | 申报类型、提交时间与报告期间分别使用 |
| 财报 | 新浪 / Tushare | 科目与单位按来源解释;无历史版本保证,不能据报告期做严格 PIT |
| 业绩预告/快报 | Tushare forecast / express | 同一 events 数组按 kind 解析单位;部分失败不等于无业绩披露 |
| 行业 | Tushare sw_daily | 申万指数口径,不等于其他提供方的概念板块 |
| 北向/南向 | Tushare moneyflow_hsgt | 北向按披露时期区分指标;南向原字段口径未确认,不能计算日净流入 |
| 新闻/研报 | 东财、见闻、RSS | 只作线索,不保证完整覆盖或历史档案 |
| 宏观 | Tushare、东财镜像、中债、海外官方源 | 区分数据期间、发布日期和取得时间;数据可能修订 |
| 搜索/正文 | DeepSeek / Tavily | 搜索只作发现;正文提取可能失败或缺失内容 |

换源时重新核对指标、日期、币种和单位,不要直接拼接序列。
失败按 `error-playbook.md` 处理;不能通过吞异常返回空数组来掩盖故障。
